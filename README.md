# Agentic RAG Assistant for Wise Policies

An intelligent document assistant using Agentic RAG with multi-step reasoning, tool use, and verification.

## Features
- 🧠 Multi-step planning and reasoning
- 🛠️ Tool use (search, calculator, verifier)
- ✅ Cross-source verification
- 📊 Comparison queries

## Quick Start
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python3 -m uvicorn server_agentic:app --reload --port 8000`
4. Open http://localhost:8000
